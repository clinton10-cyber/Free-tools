Security and compatibility

Token handling: the token is kept in page memory only; this page does not save it to local storage. Close the tab to clear it. Avoid shared devices.

Commit identity: the Gmail address is commit metadata, not your login. Use an address verified with GitHub if you want the commit linked to your profile.

Browser: use a current Chrome, Edge, Firefox or Safari version. A network connection is required for GitHub API requests.
